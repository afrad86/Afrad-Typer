# Afrad Typer

[![Download for MacOS](Resources/badge-macos.svg)](https://github.com/afrad86/Afrad-Typer/raw/main/release/Afrad-Typer.zip) [![Download for Windows](Resources/badge-win.svg)](https://github.com/afrad86/Afrad-Typer/raw/main/release/Afrad-Typer-Windows.exe)

## Install

**Mac** (macOS 12 or newer, Apple Silicon and Intel)
1. Click the orange **Download FOR MACOS** button and unzip the file.
2. Drag **Afrad Typer** into Applications.
3. First launch: right-click the app, choose **Open**, then **Open** again (the app is not notarised). If macOS still blocks it, run `xattr -cr "/Applications/Afrad Typer.app"` in Terminal.

**Windows**
1. Click the blue **Download FOR WINDOWS** button.
2. Double-click `Afrad-Typer-Windows.exe`. There is nothing to install.
3. If Windows shows a blue "Windows protected your PC" box, click **More info**, then **Run anyway** (the app is not code-signed).

## What it does
- Lessons from words, common words, trigrams, tetragrams or your own list, with automatic weak-key, slow-pair and slow-word practice mixed in.
- Timed tests, passages, numbers and symbols.
- An optional Advanced ladder from 45 to 110 WPM. Each stage lesson is 200 words. Finish 30 lessons, with at least 90% of your latest 30 reaching the stage speed and accuracy (97% up to 85 WPM, 96% from 86 WPM), to unlock the next stage.
- Separate users, each with their own progress, an optional picture and an optional password.
- Progress charts, a weak-spot report, a passage library and a Focus mode.

## Your progress
- Progress stays on the computer you use, separately for each user. It is never uploaded anywhere.
- To move it to another computer: **Progress > Export backup** on one, **Import backup** on the other (same user name). Backups merge, so nothing is duplicated.
- Mac only: turn on "Sync my progress between Macs with iCloud Drive" on the "Who is practising?" screen (on both Macs, same user names) to keep progress in step automatically.
- The Mac app also saves a weekly automatic backup (Progress > Show weekly backups).
- If a user forgets their password it cannot be recovered.
